# DIY Robot Dog Top Kit

The **DIY Robot Dog Top Kit** is an exciting and engaging project for young innovators and DIY robotics enthusiasts. Powered by a single servo motor, the kit brings the robot to life by enabling synchronized head and tail movements.

The assembled top kit can be easily mounted onto the **DIY Robot Dog Base Kit** to create a complete, interactive robotic pet. This hands-on project offers a fun way to explore robotics, servo motor control, and mechanical movement
