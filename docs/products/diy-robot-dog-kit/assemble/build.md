## Before You Start

Make sure all parts are available before beginning the assembly.

You will need:

- Micro:bit
- Expansion board
- Two servo motors
- Front and back leg parts
- Head, neck, body, and tail parts
- Screws and nuts
- IR sensor
- IR remote control
- Rubber bands
- Ice cream sticks

## Assembly Overview

The Robot Dog is built in the following stages:

1. Set the servo motor horns.
2. Assemble the front leg mechanism.
3. Assemble the back leg mechanism.
4. Attach both front and back legs.
5. Fix the legs to the body.
6. Attach the head and neck.
7. Mount the micro:bit and expansion board.
8. Connect the IR sensor and servo motors.
9. Upload the program and test the Robot Dog.
